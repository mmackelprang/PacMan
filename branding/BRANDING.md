# Chomp — brand guide

**Proposed display name:** Chomp
**Tagline:** *The maze, faithfully recreated.*

## Why this name

"Pac-Man" is Bandai Namco's trademark, so the suggested public face is **Chomp** — the verb the whole game is. The repo name can stay; the display name keeps you safe on any public page.

## The mark

The wedge-mouthed disc mid-chomp on a dot trail. Generic enough to be yours, instantly readable anyway.
